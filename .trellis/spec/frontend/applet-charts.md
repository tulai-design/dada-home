# Applet 趋势图

## 公开协议与数据边界

趋势图是Applet宿主积木，入口为catalog的LineChart，经runner白名单构造JSON、UiTree渲染。lineChartData.ts集中unknown输入校验和摘要，目录引用同一限额。默认不加外部图表库或开放任意React UI导入；选型见当前任务研究。

最多120个标签和4个系列；每序列values长度与labels一致，有限数值绝对值不超过1e12，null为显式缺失。零/负数不丢弃，缺失不变0、折线不跨缺口；超量/非法输入明确局部错误，不静默截断，不让整个应用抛错。空/全缺失、单点、常量和混合正负都要有可解释行为。分类横轴按输入顺序等距排列，不假装日期比例轴。

## 展示与生命周期

SVG只负责有界折线展示；主题读CSS token，系列同时用线型区分。按真实内容容器减少刻度，纵轴留白须容纳格式化后的完整刻度（包括微小负值的科学计数法），不能裁掉负号。完整标签和值由可访问明细提供，不能只靠鼠标hover。明细表自身可横滚，不能撑大外层；说明精确值与轴上缩略值的区别。数据内容作为React文本，不拼接HTML/CSS。

复用useContainerWidth，提取hook时保留旧导出兼容。尺寸/主题只更新图形，不改runner srcdoc或业务key，不请求/写存储/重启init。图表默认无动画，status形态由应用返回简短Text。既有Bars行为保持，不能在新增折线时偷偷改变其协议。

## 验证

沿公开目录→runner JSON→UiTree的行为边界，数据检查观察可读错误/摘要，图形观察真实内容/有限坐标/缺失段行为，不对图表库私有结构或提示词全文做快照。真实Applet示例验证设置、persist与空态，320/375/768/1440与宽窗口内窄容器、双主题、键盘/触摸明细、长标签、微小正负值的实际文字边界、过量拒绝；resize/theme后业务状态和初始化次数保持。
