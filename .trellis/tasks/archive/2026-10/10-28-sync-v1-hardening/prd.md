# 同步协议与配置范围

状态：completed；本轮从新协议实现，不兼容旧同步格式。父任务：[存储与同步](../../../10-28-storage-sync/prd.md)。

## 目标与授权

2026-10-28 用户确认只有本人测试使用，可以按全新开发处理，不需要旧代码、旧实例或旧协议兼容。保留完整本地使用，先交付 Gist 配置同步与 WebDAV/HTTP 全业务快照的可信协议；不自动清空当前测试数据或写真实远端。

## 要求

- 显式 v2 协议、范围与记录 codec，输入为 unknown；未知版本、未知记录目标、坏值、坏加密信封、HTTP 错误不能当空文件覆盖。旧 v1 明确拒绝，无自动迁移、双写或 raw 逃生格式。
- Gist 固定 configuration 范围：工作空间设计/应用源码与设置、明确宿主偏好、人格的当前性格配置；排除聊天、画像/累积记忆、组件业务数据、App/Applet 状态和本机授权/连接。WebDAV/HTTP 为 full，包含可携业务数据及完整已结束聊天。出入站使用同一白名单。
- API Key 等已知凭据默认排除，只有启用同步密钥且有加密口令才携带；工作空间网络授权、同步连接和设备运行状态始终本机。应用源码或自由文本可能含用户手写敏感内容，界面不得保证自动识别。
- 新增/更换/移除加密、关闭密钥同步，即使业务未改也要改写远端表示；轮换可提供本次解密原口令，不建立旧格式兼容。关闭密钥后清除本次快照已知凭据，不能保证抹除供应商历史。
- 元数据绑定新协议、提供方资源与范围；采用逻辑记录身份独立于存储位置，不再保留旧 ls 身份迁移层。版本比较确定收敛，同一毫秒不同内容不能假报最新；不按时间自动回收墓碑。
- 网络等待期间发生本地修改时保留本地，应用前在保存门禁内复查；坏包与本地保存故障不产生删除。入站应用借用可恢复存储提交，不以跨引擎逐条写冒充原子。成功拉取后保持只读待重载，防止旧内存缓存覆盖已更新磁盘；不自动刷新丢掉输入。
- Gist raw/metadata 明确状态、形状、预算、限流与超时；WebDAV/HTTP 创建条件和已有 ETag 条件分开。无强 ETag及 Gist 显示无并发保护，不假称 CAS。限流冷却期间零网络，不长时间 sleep。
- 设置页准确展示范围、整包传输、实际字节/逻辑记录数、提供方并发能力与错误/冷却；连接测试不写远端。切换连接或范围时不能串用 meta、异步创建 Gist 不能改错连接。

## 验收

- [x] 公开同步入口覆盖 v1/v999、坏 records/目标/信封/关联、口令错误：本地/远端均不变，无新墓碑。
- [x] Gist 新快照只含配置；伪造聊天/业务/本机权限记录入站拒绝；WebDAV/HTTP 可同步合成业务与聊天，活动轮次不被判删除。
- [x] 从明文到加密、原口令轮换/移除、关闭密钥同步均无须业务修改即可正确写回；默认补回本机连接/凭据，不替换本机授权。
- [x] GET/PUT等待期间编辑不被覆盖；版本确定比较，同版本不同内容有确定处理；长久墓碑仍保留，连接/范围切换不串 meta。
- [x] HTTP200空正文、Gist raw500/截断/超量、429/403与timeout明确失败；冷却零网络，404首次创建与412竞态有行为回归。
- [x] 真实隔离浏览器验证两设备配置/全数据传输、实际设置入口、移动/桌面双主题、错误/冷却与备份恢复不回归。
