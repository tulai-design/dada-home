# 增强 Applet 数据图表能力

父任务：`10-27-ai-builder`。批准来源：2026-10-27 用户确认三批增强方向并要求建立 Trellis/Matt 工作流。

## 用户问题与交付行为

用户让 AI 制作记账、习惯或监控小工具时，除已有简单柱状图外，还能使用统一的趋势/折线图，在窄容器中看懂数据。

## Blocked by

无；可独立推进。

## 验收标准

- [x] 先选定并核对兼容的图表实现，封装为宿主可发现的组件，保留现有 Bars 行为。
- [x] 目录和运行时支持必要数据协议、主题映射、缺失/空/错误数据状态。
- [x] 窄屏调整刻度和图例，提供可读摘要或表格，触摸与键盘可获取关键信息。
- [x] 限定或聚合过量数据点，布局变化不会丢失应用状态或重复请求。
- [x] 一个 AI 可用的趋势工具示例通过真实尺寸与双主题验证。

## 测试决策

通过 Applet 目录→声明→宿主渲染的公开协议验证；数据摘要使用已知样例，图表库私有结构不作为断言。

## 范围外

不安装后直接要求 AI 任意导入图表库，不新增远端计费数据源。

实现与验收已完成，详见 design.md、implement.md 和 verification.md；提交与归档按会话授权执行。
