# 增强 Applet 数据管理能力

父任务：`10-27-ai-builder`。批准来源：2026-10-27 用户确认三批增强方向并要求建立 Trellis/Matt 工作流。

## 用户问题与交付行为

用户能让 AI 制作长期使用的记录型工具，支持查找、排序、分页和详情，并在手机/抽屉中完成操作。

## Blocked by

无；可独立推进。

## 验收标准

- [x] 保留现有简单 Table，新增受控数据管理协议与统一 Lobe 操作控件。
- [x] 筛选、排序、分页、选择的状态语义清楚，持久业务数据与临时视图状态区分。
- [x] 窄容器按列优先级或详情视图显示，不把宽表简单缩小；键盘/触摸可完成核心流程。
- [x] 空数据、无匹配、错误及长文本有明确处理；依赖版本与文档一致。
- [x] 一个记录型工具贯通增删或查看→筛选排序→窄屏详情→恢复验证。

## 测试决策

通过 Applet 用户可操作行为验证，不依赖第三方表格库内部状态；选库前核对当前版本，不能混用 v8/v9 API。

## 范围外

不引入后端数据库、多用户协作或替换现有所有列表。

## 计划状态

实现与验收完成，技术合同、测试证据见design.md和verification.md；提交归档按会话授权执行。
