# 应用业务数据增量同步接入

父任务：可选自建增量同步服务。用户已授权继续实施，本轮交付 apps 业务的程序接入，保持纯本地使用。

## 行为

- App/Applet 保存与待同步意图在同一 IndexedDB 事务提交；离线保存不依赖服务。
- 首次启用扫描已有应用状态，后续只传待同步改动。8 MiB、100 层 JSON 能力不缩水。
- 密文和操作 ID 在发送前持久化；中断、响应丢失后复用原操作；确认旧版本不能清掉新编辑。
- 入站先认证解密，再将业务、远端版本、冲突与游标在同一事务提交；失败不跳游标。
- 同记录修改及删除/修改保留双方，显式选择后才能继续；卸载仍保留业务数据。
- 凭据默认留在本机；口令/令牌/明文 keyring 不进入同步队列或普通备份。
- 远端应用成功后阻止旧运行实例写回，返回需重载状态。备份恢复与整包同步不得绕开活动绑定。

## 验收

- [x] 两个隔离浏览器 origin 使用真实 IndexedDB 与临时真实 HTTP 服务，初次同步与第二次增量均可见；记录请求/字节。
- [x] 服务不可达仍可保存；重建客户端后队列继续；丢响应重试不重复提交，旧确认保留期间新编辑。
- [x] 不同记录合并；同记录及删除/修改冲突保留双方；显式解决后收敛。
- [x] 下载/解密失败不推进游标；下载期间本地编辑保留；写事务失败不留下半份业务/队列。
- [x] 大对象、深层 JSON、特殊合法应用 ID、已知凭据字段与空对象/删除区别通过验证。
- [x] 类型检查、完整测试、构建及 Standards/Spec 审查通过。
