# 首页组合与草稿预览应用

父任务：`10-27-ai-builder`。批准来源：2026-10-27 用户确认三批增强方向并要求建立 Trellis/Matt 工作流。

## 用户问题与交付行为

用户可以选择极简、效率、编辑式或视觉展示方向，在不覆盖当前页面的草稿中预览和修正，再整体应用或取消。

## Blocked by

`10-27-page-sections`、`10-27-page-inspector`、`10-27-effect-theme-fallback`

## 验收标准

- [x] 四类组合具有明确内容层级、窄容器规则、两种主题和空数据处理。
- [x] 草稿与当前工作空间隔离，预览/取消不污染页面和业务数据，应用形成可撤销的完整变更。
- [x] AI 能选择和调整组合，运行可用检查并报告实际检查范围。
- [x] 已有模板/撤销基础复用，应用安装、挂载 ID 和私有数据不因改版丢失。
- [x] 对同一请求演示生成→检查→修正→应用→撤销，不把主观满意度作为自动通过条件。

## 测试决策

以草稿生命周期和最终工作空间状态为公开入口，配合实际多尺寸/双主题预览；照片/动画上的可读性仍需视觉检查。

## 范围外

不提供自动公开发布站点，不承诺同一风格满足所有人。
