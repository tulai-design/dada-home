# README 产品展示与一键部署

## 目标与授权

用户要求全面、吸引人、图文并茂的 README，支持 Vercel 一键部署按钮；允许自行截屏，可选 AI 品牌图提供提示词由用户生成。用户选择真实截图为主、简约 iOS 风。当前授权完成制作、本地验证和本地提交，不部署或推送。

## 范围

- README 首屏品牌、产品价值、真实截图、主题/AI搭建/应用/日常工具/本地数据与同步/扩展/PWA功能介绍，清晰快速开始与部署入口。
- 深层使用、部署与开发说明移至有索引的中文文档，保持功能说明可找到，不删重要数据/权限边界。
- 真实应用截图来自独立浏览器配置的合成展示数据，不读取用户存储或真实服务凭据；演示内容明确披露，不伪造实际模型执行证据。
- 可用的 Vercel 配置及按钮，处理标准默认取数代理与 SPA/静态资源路由，复用现有代理安全合同；不以按钮代替部署配置，不执行线上部署。
- README所用素材纳入docs目录，截图可复现；可选品牌视觉提示词单独中文文件，当前成品不依赖用户尚未生成的图。

## 验收

README 在 GitHub Markdown 中可读，实际图片/本地链接存在，首屏及窄屏排版检查。所有功能与当前实现一致，截图无隐私凭据。Vercel 按钮指向真实仓库与有效配置，构建和适配器测试通过；未真实部署明确说明。纯文档不写字符串快照。
