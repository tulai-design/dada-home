# 默认采用 iOS 与玻璃 Dock

## 目标与范围

用户要求默认外观从纸张改为 iOS，Dock 默认玻璃。首次初始化、缺失外观值、默认外观查询与全量外观还原统一采用新默认。保留纸张预设及其样式基底语义；显式已保存的主题与 Dock 选择不自动覆盖。已有首页内容、默认背景图层、布局与业务数据不改。

## 验收

- [x] 新工作空间初始启用 iOS，默认 Dock 为玻璃。
- [x] get_appearance 默认说明与真实默认一致；reset_appearance 全量还原采用 iOS 和玻璃，并保留内容、库与明暗策略。
- [x] 读取缺失/无效外观值回落一致；已保存的有效主题与 Dock 继续生效，纸张仍可手选。
- [x] AI 提示、技能与产品文档不再宣称纸张/纸质 Dock 为产品默认。
- [x] 相关现有测试、完整测试、类型检查通过；隔离浏览器检查初次加载与明暗/窄屏。
- [x] 在 main 本地提交，归档记录；不推送、不重装依赖。

## 实现边界

改动属于 workspace 默认选择、dock 默认、appearance 查询/还原与主题回落，不重做皮肤、不迁移用户已有选择、不改首页默认装饰、不改其他主题定义。纸张的 default ID 仍作为 CSS 基底预设，不通过更换其 ID 破坏模板等既有语义。
