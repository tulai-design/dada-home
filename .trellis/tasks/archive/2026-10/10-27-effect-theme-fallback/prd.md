# 特效双主题配色与静态内容降级

父任务：`10-27-ai-builder`。批准来源：2026-10-27 用户确认三批增强方向并要求建立 Trellis/Matt 工作流。

## 用户问题与交付行为

用户切换浅深主题或遇到特效加载失败时，页面内容仍可读；标题、数字和正文不会随动画一起消失。

## Blocked by

`10-27-effect-policy`

## 验收标准

- [x] AI 可使用语义色板或分别配置浅深模式；现有固定色配置有明确兼容路径。
- [x] 减少动画、加载失败或 WebGL 不可用时，装饰安全退化，承载文字的效果保留静态语义内容。
- [x] 切换主题不会重置业务状态，重试/切换效果能恢复正常显示。
- [x] 至少覆盖文字、卡片、背景三类真实渲染与两种主题，声明未覆盖的复杂场景。

## 测试决策

以同一组件在正常/失败/减少动画/主题切换下的可见内容和状态为测试入口，不测试 error boundary 私有字段。

## 范围外

不把所有旧用户指定颜色强制替换；不改变主题默认还原契约。

## 计划状态

实现和双轴复核已完成；测试与覆盖边界见verification.md。已提交19b0c78并归档。
