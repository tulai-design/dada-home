# 完整加密同步与重复同步修复

用户要求同步全部业务数据，当前实际遗漏业务凭据和连接配置，主题可能因拉取提前停止而未到达，搜索配置缺 keys 导致设置首页崩溃。

## 验收
- [x] 自建加密增量同步包含主题、工作空间、业务设置、搜索/AI 凭据与服务地址、组件/应用数据、聊天；明确本机权限和同步设备身份例外。
- [x] 一次手动同步完整处理多页，不能在上限处虚报完成；应用远端后旧内存禁止编辑，整轮结束提示刷新。
- [x] 首次、重复手动同步、刷新重进均安全；缺失或损坏搜索配置不会使页面崩溃。
- [x] 新设备可得到主题和完整业务配置；密钥删除能同步；快照同步已有范围/密钥策略不被意外改变。
- [x] 有真实双 origin/HTTP/IndexedDB 回归与类型、完整测试、构建证据。

不操作用户真实存储或生产同步服务；不要求兼容旧实例；每轮检查通过后提交。
