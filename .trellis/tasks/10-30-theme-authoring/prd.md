# Agent 主题定制与隔离预览

## 目标与依赖

父任务：theme-shell-architecture；blocked_by：shell-host。人和Agent通过一套可发现的主题能力创作完整变体，修改可校验、可预览、可取消，确认后一次应用。

## 需求

- R1：一份字段目录驱动运行校验、设置表单、Agent schema/按需说明及有效值来源。覆盖真正消费的token、部件recipe、外壳参数与受控资源，类型/范围/作用域/适用能力清楚。
- R2：作者模块提供发现、派生草稿、显式作用域patch、验证、预览、应用/取消，UI和Agent共用。未知字段或跨字段非法整次拒绝。
- R3：草稿id/revision与来源主题修订明确；应用前检查选择/依赖冲突，保留草稿，不覆盖期间其他业务编辑；一次正式commit，撤销可恢复，取消无正式写入。
- R4：主题预览与正式主题、portal、资源和业务副作用隔离，只用典型静态宿主夹具，不启动第二份真实应用/存储/同步/AI。
- R5：更新design-system单一正文与主提示，按需发现替代逐主题警告；数据校验、有限几何、实际截图验收分别表述。

## 验收

- [x] 实际Agent工具从发现到派生、修改双模式/外壳参数、取消或确认应用全链路可执行，错误是失败事件且可解释。
- [x] schema、表单、有效值和渲染一致，拼错token/非法范围/不支持能力不部分提交。
- [x] 正式与预览同时不同主题，modal/drawer/toast/window无相互污染，预览零真实业务保存/模型/同步调用。
- [x] 过期草稿/主题切换冲突/资源失败保留当前主题；应用一次undo，页面/应用/助手状态保持。
- [x] tsc/test/build与双模式/容器/资源失败浏览器回归通过，现状文档如实说明预览限制。

## 范围外

不开放任意宿主CSS选择器、JSX或第三方代码；不承诺模型自动看图/自动审美验收；不扩大首页布局草稿为整站事务。
