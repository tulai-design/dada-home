# 完整新标签页扩展与下载入口

## 目标与授权

用户已确认从可行性研究进入实现：开发者模式自用 Chrome/Edge 新标签页扩展，增加下载与安装入口，并明确要求保留所有现有功能、保证体验。沿用 main 开发、本地提交，未授权商店上架或远端部署。

## 范围与行为

1. Web/PWA 与本地扩展共用现有 React 主应用、主题、Dock、组件、特效、AI 工具、App/Applet、书签、备份与同步。不复制产品实现或通过远程整站代替本地主页。
2. 一条构建命令产出可加载目录和 ZIP；网站构建包含下载文件，开发环境也可下载已构建的包。
3. 在设置提供明确的浏览器扩展入口，含 ZIP 下载、解压、Chrome/Edge 开发者模式加载及更新说明；说明网页与扩展数据独立，可用备份或同步转移。
4. 扩展内原生连接书签；原有网页书签桥仍可用。
5. 扩展通过明确用户操作申请网络来源权限，保留生成应用自己的域名授权；拒绝/撤销/取消请求有可见结果，不请求任意网页读取或历史权限。
6. App/Applet 以包内隔离沙盒运行，现有生成逻辑、交互、保存、主题、设置、形态协议保持；验证外部模块导入路径。
7. 采用单编辑运行实例保证数据安全，其他新标签页可访问现有运行实例；关闭/交接后从持久化重新初始化，不让旧缓存写回。避免重复 AI 应用、自动同步和未提交保存丢失。此轮不建设跨标签页协同编辑。
8. 扩展不注册网页 PWA、不注入远程统计；网络依赖仍需要连接配置和实际网络。关闭运行页面会中断当前 AI，不承诺后台常驻。

## 验收

- Chrome 开发者模式加载构建目录后，真实新标签页打开完整应用，默认 iOS/玻璃 Dock，浅深色及窄屏可操作。
- App/Applet 交互、持久化重载、主题上下文通过真实 MV3 页面验证；网络授权成功/拒绝、模型流式响应使用合成服务验证。
- 两个扩展页面不能同时从旧缓存写回；实例接续读取最新持久化，无重复后台工作。
- 下载入口可见且链接实际 ZIP；ZIP 根目录含有效 manifest、主页和沙盒资源，解压可加载，不包含递归下载包或用户数据。
- 网页功能回归，tsc、完整 test、Web/扩展 build 通过；记录真实浏览器检查与限制。

## 范围外

商店发布、推送部署、Safari/Firefox 专用版本、网页自动操作、侧边栏、永久后台 Agent、真实用户数据迁移。
