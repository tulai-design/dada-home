# 掌机主题设计

## 边界

皮肤是内置主题加一份样式，沿用 iOS 的接法。`PIXEL_THEME` 放在 `src/lib/workspace.ts`，`readThemes` 注入并丢弃同 id 旧副本。`App.tsx` 在 `theme.id === 'pixel'` 时写 `dataset.skin = 'pixel'`，否则不留这个值。样式只写在 `:root[data-skin='pixel']` 下。

纸张和 iOS 的规则不动。掌机离开后，那些选择器不再匹配。

## 色板

只用这四色。浅色是亮屏，深色把角色对调。

| 角色 | 浅色 | 深色 |
| --- | --- | --- |
| bg 屏幕 | `#8bac0f` | `#0f380f` |
| bg2 面板 | `#9bbc0f` | `#306230` |
| bg3 凹槽、按下 | `#306230` | `#8bac0f` |
| text | `#0f380f` | `#9bbc0f` |
| text2 | `#306230` | `#8bac0f` |
| text3 / text4 | `#306230` | `#8bac0f` |
| border / rule | `#0f380f` | `#9bbc0f` |
| main | `#0f380f` | `#9bbc0f` |

共享：`radius` 和 `radius-lg` 为 `0`，`frame` 为 `8px`，`frame-gap` 为 `8px`，`frame-color` 为 `#0f380f`。桌面外框是机身边，不是纸张的红线。手机上现有样式已经不画整屏外框。

## 材料

- 阴影一律 `2px 2px 0` 当前文字色，不用 `blur`。
- 分段控件：槽用 `--bg3`，滑块用 `--bg2`，带同样的错位阴影。
- 选中行反色：底用最深的绿，字用最亮的绿。
- 首页 `.app::before` 纸纹和 `.fx-root` 波纹在这套皮肤下不显示。
- 顶栏底部那条四色色带去掉。
- 手机设置沿用 iOS 已经验证过的结构：藏起 `.canvas > .topbar`，`.page` 底部不留空档，滚动内容自己留出 Dock 高度。选择器换成 `data-skin='pixel'`，避免两套皮肤互相改。

## Dock

不写入存储。`visibleDock` 只在 iOS 把默认纸卡显示成玻璃。掌机另加一条：启用时若存储预设是 `glass`，显示成 `solid`，自定义 Dock CSS 仍保留。通栏 `bar` 保持通栏，只换颜色和直角。皮肤 CSS 把 `.dock` 收成实色方条，关掉液体玻璃滤镜。

## 字体

标题、时钟、按钮、设置标题使用内置像素字（可商用、含常用中文，随构建打包，不走 Google Fonts）。正文和设置行继续用无衬线，保证长句可读。像素字只在 `data-skin='pixel'` 里引用，不进主题的 `fonts` 数组，避免和 Google 字体管道缠在一起。

若完整字库太大，先子集到界面会用到的汉字和拉丁数字，不阻塞第一版的边、色和阴影。

## 提示词

`src/lib/ai.ts` 的主题说明补一句：掌机预设 id 是 `pixel`，直接切换，不要另存。三套内置主题性格不同，不要把纸张的红写进掌机。

## 取舍

- 深色留在灰绿里。夜里换成黑红或纯黑会变成第四套主题。
- 正文不用像素字。全像素中文在 14px 正文里难读，也更重。
- 图标保持矢量。`image-rendering: pixelated` 会把 Phosphor 弄脏。
