# 像素风主题

## Goal

给搭搭加一套内置「掌机」主题。它用灰绿色板、实线、错位阴影和像素字，把首页、Dock、搜索和设置换成同一块液晶屏。三套内置主题各有性格：纸张是红，iOS 是系统蓝和毛玻璃，掌机是灰绿和硬边。聊天里的搭搭只切换这套主题，不另存一份仿制品。

## 已确认

- 气质是掌机桌面。同一套首页、Dock 和设置分组，不做成游戏菜单，也不做成终端。
- 色板是灰绿。用户要求每套主题个性化，掌机不借用纸张的红。
- 纸张是默认气质：米白、墨色、红色点缀、方角。见 `docs/design-system.md`。
- iOS 由 `data-skin="ios"` 打开手写样式，只有主题 id 为 `ios` 时生效。`readThemes` 始终注入当前定义，丢掉同 id 的旧副本。见 `src/lib/themes.ts`、`src/App.tsx`。
- 主题变量改不到选择器。页面和组件 CSS 也不能写选择器。像素皮肤跟 iOS 一样手写。
- 圆角已经是 0。像素感来自有限色、实线、无模糊阴影和像素字。
- 仓库里没有字体文件。Google 字体管道只接受英文字体名，中文像素字要另备。

## Requirements

1. 内置主题 id 为 `pixel`，名称能看出是掌机。内置主题不能改、不能删；读入时用当前定义覆盖同 id 旧副本。
2. 启用时设置 `data-skin="pixel"`，离开时去掉。纸张和 iOS 的皮肤互不叠用。
3. 浅色和深色都留在同一套灰绿里，偏灰、大面积不荧光。浅色底 `#c5d2ae`，深色底 `#1a2218`。主色不用红、不用系统蓝。
4. 关掉外框只收起机身边，不另存主题，皮肤还在。切到别的主题后这个开关不跟着走。纸张主题仍按原样另存。
5. 材料：直角、约 2px 实线、`2px 2px 0` 的实色错位阴影。没有渐变、毛玻璃、发丝线和纸纹。
6. 首页装饰波纹在这套皮肤下不显示，屏幕是平的液晶底。
7. 搜索框、卡片、分段控件、设置分组、组件市场和顶栏都用同一套硬边。设置列表和组件列表各自收成一块面板，不要每行一个盒子。手机上的设置页藏起系统顶栏，内容可以从 Dock 后面滚过，和 iOS 一样是一整块，但颜色和形状是掌机的。
8. Dock 在这套皮肤下显示成实色像素条，不改已存储的 Dock 预设。离开主题后恢复原来的纸质卡片、玻璃或通栏。
9. 标题、时钟、按钮和设置标题用像素字。正文和设置行保持可读的无衬线，避免长中文发糊。
10. 运行时提示告诉搭搭：用户要掌机风格时直接切换 `pixel`，不要另存一份。

## Acceptance Criteria

- [ ] 主题库里有掌机预设；切换后浅色是灰绿液晶，深色仍是同一套灰绿，文字可读。
- [ ] 首页没有纸纹和柔和波纹；搜索框、卡片、Dock、设置分组是直角实线，阴影不模糊。
- [ ] 手机设置页没有系统顶栏，列表能滚到 Dock 后面；滑到底时最后一行仍能停在 Dock 上方。
- [ ] 切回纸张或 iOS 后，红框、毛玻璃、分组白卡片和原来的 Dock 预设都还在。
- [ ] 存储里如果写过一份 id 为 `pixel` 的旧主题，读入后仍是现在这份预设，且不能被保存或删除。

## 不做

- 不让聊天里的搭搭自己写皮肤。
- 不改纸张和 iOS 的外观。
- 不加血条、背包、扫描线、光标闪烁。
- 不把 Phosphor 图标栅格化。
- 不把 Dock 的预设写进存储。
- 不推送、不发布。
