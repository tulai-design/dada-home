# 响应式首页布局积木

父任务：`10-27-ai-builder`。批准来源：2026-10-27 用户确认三批增强方向并要求建立 Trellis/Matt 工作流。

## 用户问题与交付行为

AI 可以组合主视觉、内容分区和主次分栏，并在手机、窄分栏中保持清晰的内容顺序。

## Blocked by

无；可独立推进。

## 验收标准

- [ ] 新增少量有语义的布局结构，保持旧有扁平页面兼容，不迁移或丢失组件 ID 与应用挂载。
- [ ] 目录可发现布局规则，AI 使用受控参数表达桌面/紧凑容器布局。
- [ ] 实际容器变窄时按规则重排，长标题、空内容、键盘顺序和主题均可用。
- [ ] 新增结构支持模板、保存、恢复与撤销；首个完整布局可独立演示。

## 测试决策

工作空间公开操作/模板恢复验证兼容，真实浏览器验证 320/375/768/桌面以及分栏容器；不只看 viewport。

## 范围外

不开放任意 React 代码编辑宿主，不在此任务加入一整套营销页模板。

## 计划状态

本 PRD 固定用户行为和边界；复杂任务在 start 前补齐 design.md、implement.md，并核对依赖及接口。当前不表示实现已开始。
