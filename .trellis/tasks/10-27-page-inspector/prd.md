# 为 AI 提供真实页面检查反馈

父任务：`10-27-ai-builder`。批准来源：2026-10-27 用户确认三批增强方向并要求建立 Trellis/Matt 工作流。

## 用户问题与交付行为

AI 修改后可以获取当前实际渲染的尺寸和确定性问题，修复后重新检查；没有测量或无法判断的内容明确返回未知。

## Blocked by

无；可独立推进。

## 验收标准

- [x] 只读检查工具返回页面与容器、主题、可见状态、时间或版本信息和稳定的问题标识。
- [x] 能报告横向溢出、明显裁切和结构性问题；每条问题定位到相关组件并给出测量依据。
- [x] 未挂载页面、跨源 iframe、Canvas 或无法推断的对比度返回不可测/未知，不编造通过。
- [x] 检查不会泄露聊天、密钥、表单私密内容，不写工作空间、不进入撤销历史。
- [x] 构建一处真实溢出→检查定位→修复→复查消失的验收路径；检查说明不声称审美已验收。

## 测试决策

公开只读工具与真实 DOM 夹具为入口；独立检查是否改写状态。截图属于后续能力，不能用配置推测代替实测。

## 范围外

本任务不做任意页面截图上传、多模态模型适配或跨域 DOM 抓取。
