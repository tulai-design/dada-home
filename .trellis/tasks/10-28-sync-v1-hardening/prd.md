# 兼容同步可靠性与Gist边界

状态：planning；行为范围已拆分，激活前补具体 design/implement。父任务：[存储与同步](../10-28-storage-sync/prd.md)。

## 目标

继续使用现有存储的用户获得可信错误和兼容保护，修复会造成误删、泄漏策略失效或错误覆盖的问题。

## 要求

- 严格验证同步协议与加密信封，未知版本、缺失 recs、坏密文和远端错误不得当成空库覆盖。
- 加密口令或是否同步密钥变化，即使业务值未变，也要更新当前远端表示；关闭密钥同步清理本次快照的已知敏感字段。说明旧远端历史仍可能存在。
- 验证 Gist raw 状态、实际体积边界和限流退避；保留已有 truncated 支持。WebDAV/HTTP 根据真实能力处理条件更新与首次创建。
- Gist 无已验证 CAS 能力时明确显示并发边界，不用重读或状态为成功冒充冲突保证；安全的多设备并发由增量服务承担。
- 把逻辑记录与本地地址解耦，为应用迁移保留旧 ls ID 的入站/出站适配边界；回落组件数据纳入完整收集。
- full 拉取应用前复核本地版本，保留等待网络期间发生的新编辑；相同非零时间戳而不同内容必须确定收敛或显式保留冲突，不能假报最新。
- 移除仅按 90 天就判安全的墓碑回收假设；新客户端在没有设备确认协议时采取保守保留，并说明旧客户端仍可能执行旧策略，不能承诺修复未升级代码。
- Gist 默认且仅同步明确可携带的配置，排除聊天、工具明细和应用业务状态；网络凭据/机器本地配置仍按安全策略排除。旧远端排除项在范围切换后不应用到本地、不生成删除；现有 v1 整包传输可能仍携带原有值，只作原样保留，不再从本机新增或更新这些记录；WebDAV 与 HTTP 保留原全数据能力。配置同步只是逻辑分类，应用源码可能仍较大，要继续执行体积边界。

## 验收

- [ ] 隔离夹具覆盖加口令无业务变更、关闭同步密钥且远端残留字段、v999、坏 recs、raw 500、429/403退避。
- [ ] Gist >1MB 路径正确走 raw，超可读边界明确失败；不把读取失败当首次创建。
- [ ] WebDAV/HTTP 创建竞态、ETag冲突有可预期结果；无条件写能力状态真实呈现；Gist限制有回归。
- [ ] 应用旧 ls ID 经过兼容适配后值和修改身份不变；不会意外同时导出 kv 副本。
- [ ] 恢复/同步失败不覆盖当前数据，错误后再次正常同步可恢复。
- [ ] GET 期间新写入不被覆盖；同毫秒不同值有确定结果或冲突；新客户端不会仅因时间过期清掉仍需防复活的墓碑。
- [ ] 空远端的 Gist 新快照不携带聊天或应用业务状态；已有远端排除项在整包中保持原值且无新墓碑，入站不写入本地、不从本机更新。WebDAV 仍同步合成完整数据；切换后端不复用错误范围的 meta。

## 范围外

不承诺Gist并发可线性化，不引入新的v1增量文件格式，不自动擦除Git历史。
