README 以真实产品截图为主，建议先只生成 **1 张方向一的品牌横幅**，用于首屏点缀。如果还想增加一点陪伴感，可选做第 2 张方向三的小插画。方向二是独立宣传海报，不是 README 必需素材；当前文档也不依赖额外配图。

现有 9 张真实截图合计约 **1.01 MiB**，保留 PNG 以保证界面文字清晰。新增品牌图优先使用优化后的 WebP，原始大图另行保存，README 中按约定尺寸展示，不直接铺满原始尺寸。不要用 AI 生成的界面替换产品截图。

## 参考图与通用约束

- 第一张参考图：搭搭 Logo / IP，作为角色身份、轮廓、服饰、配色和表情的唯一依据。保留可辨认特征，不重新设计角色。
- 第二张参考图：真实系统截图，只帮助理解产品的清爽秩序、透明材质和留白；不要求画出界面。
- 如果使用第三张艺术参考图，只借鉴构图、光线或媒介气质，不复刻其中的主体和文字。
- 按下方用途选择生成尺寸，保留四周安全留白。不要添加英文占位字、虚构应用界面、模型品牌或未经要求的标志。中文标题建议后期排版，避免错误文字。


## 交付建议

先交付原始无字大图，再单独排版标题。横幅的左侧留白和海报的上下安全区都要保留；小尺寸检查角色是否仍然清楚。素材可保存到 `docs/images/readme/`，使用英文短文件名，另保留原始大图到个人素材库，避免把多份超大生成图全部放进仓库。
