# AI 使用受控能力目录

搭搭需要让 AI 生成的页面与应用共享主题、容器适配和运行生命周期。选择把新布局、图表、数据列表及精选特效封装成宿主能力，再通过目录暴露给 AI；普通工具沿用 Lobe Applet，特殊自定义视觉才用 HTML App。

允许 AI 随意选用整套 UI 库能更快扩展源码自由度，但每个产物都需要重新解决主题、焦点、移动布局和依赖兼容。受控目录把这些成本集中在宿主，代价是每种新能力需要先完成封装。计算依赖与 UI 能力不同，现有 Applet 的计算库导入能力不因此取消。

后续将特效组合预算、语义色板、静态替代和渲染反馈纳入统一契约。这个决策确认方向，**不表示这些功能已经实现**。来源许可按引入版本记录；库运行时许可不代表全部素材资产同样授权。
