# 主题与代码扩展分层开放

决策状态：accepted，2026-10-30。实现状态：部分实施（主题身份与完整派生）；稳定宿主、作者预览、包及隔离代码扩展仍待推进。用户明确选择“声明式主题 + 单独授权的代码扩展”。本条只接受开放方式，不代表具体 Shell Interface 或创意工坊已实现。

主题通过可校验的设计数据、宿主声明的造型与桌面配置进行定制，允许人和 Agent 使用同一套作者能力。需要新增执行逻辑的扩展单独安装、明确授权并隔离运行；普通主题包不能携带任意宿主 JavaScript。宿主内运行的可信桌面外壳仍需随应用构建发布，第三方代码不能仅因声明了外壳 ID 或能力而得到同源权限。

这个选择保留创作自由，也维持现有 App/Applet 的隔离方向。代价是全新的桌面交互需要新增可信外壳能力，或另行建设受限桌面运行器；“任意远端 React 下载后直接接管主页”不属于声明式主题热插拔。包的元数据和能力描述可共用，执行过程与信任级别不能混为一谈。

架构细节与阶段提案见 [A3 设计研究](../work/research/2026-10-30-theme-shell-architecture.md)。
