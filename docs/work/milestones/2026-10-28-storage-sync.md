# 存储与可持续同步

日期：2026-10-28。本地可靠保存、新快照同步、AI 应用存储与长期聊天按需读取已通过验收；共用增量服务/SDK、五类业务集合、设置/配对和容量管理已有实现；本轮修复完整业务范围与连续拉取，服务实际部署状态不由代码检查代替。实际状态以 [Trellis 父任务](../../../.trellis/tasks/10-28-storage-sync/prd.md)及子任务为准。

## 确认的路线

用户确认保留完整的纯本地模式，允许增加可选自建同步服务。当前只有本人测试使用，已允许全新设计，不要求旧实例、旧代码或协议兼容；后续不再增加兼容迁移、双写与旧记录身份桥。先保证可靠保存、恢复和清晰的新同步协议，再提供长期聊天的增量同步，不强制注册。

后续进一步确认服务要供搭搭与 aifenjing 共用：通用记录版本/不可变对象归服务，业务投影与本地应用归各客户端，见[跨项目审查](../../../.trellis/tasks/10-28-storage-sync/research/shared-service.md)。Gist 收敛为配置同步；WebDAV 可以保留全部数据，S3 技术上也可承载全量但尚未接入。完整范围不意味着每次都重传所有历史。

聊天与内置组件使用 IndexedDB，App/Applet 现已统一到独立 apps 仓；原 100000 JSON 字符限制已替换为每实例 8 MiB UTF-8 JSON 预算，浏览器实际配额另行约束。当前 Gist、WebDAV、HTTP 同步按记录合并，但每次读整个快照，有变更时重写整个文件。Gist 原已支持超过正文截断范围时读取 raw_url；其 API 边界及适用判断见[官方资料研究](../../../.trellis/tasks/10-28-storage-sync/research/provider-limits.md)。

## 交付顺序

1. **已交付**：可靠写入与可恢复备份，阻断存储读取/保存错误变成同步删除；含旧数据迁移保护、可见失败与重试。
2. **已交付**：新快照协议、Gist 配置范围、加密策略、并发与供应商错误处理；不兼容旧同步文件。
3. **已交付**：AI 应用统一 IndexedDB、事务确认与失败重试、8 MiB UTF-8预算，完整备份与同步共用独立逻辑身份。
4. **已交付**：会话和轮次索引分页、工具正文按需读取、独立模型上下文，完整历史可备份恢复；备份 v3。
5. **开发已交付并归档**：可选自建同步服务与客户端，游标、幂等、离线重试、冲突恢复及部署配置；后续产品/部署验收由用户负责。
6. 分类容量、同步范围、导出和清理管理。

依赖和验收在[实施地图](../../../.trellis/tasks/10-28-storage-sync/implement.md)维护；架构边界见[设计方向](../../../.trellis/tasks/10-28-storage-sync/design.md)。不把「创建任务」写成「功能已交付」。
