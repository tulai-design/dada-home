# 搭搭：产品定位与当前能力

状态：当前产品上下文。核对日期：2026-10-28。

搭搭是本地优先的 AI 个人主页搭建助手。用户通过自然语言或手动配置，把搜索、阅读、日常事务和小工具组织成自己的数字空间；满意的页面设计可以保存成模板继续复用。

## 核心体验

1. 打开主页，立即使用常用信息和操作。
2. 告诉 AI 想增加的功能或想调整的风格，AI 读取当前工作空间并调用工具修改。
3. 在组件市场管理功能与 AI 应用，按需放入页面、Dock 或状态栏。
4. 调整主题、设置和入口，保存设计；通过撤销、模板或备份处理不同层次的恢复需求。

界面默认沿用编辑部风格的纸面主题，信息主次、可读性和操作效率优先。风格选择可以改变，但手机、窄容器、明暗模式和键盘操作不能因此失效。

## 当前能力地图

| 领域 | 已有能力 | 当前边界 |
| --- | --- | --- |
| 页面搭建 | 页面与组件编辑、主视觉/内容/主次分区、四类首页组合与布局草稿，页面壁纸、CSS、特效图层 | 草稿预览是静态布局，不启动真实业务应用或完整动态背景 |
| 信息与日常工具 | 搜索、时间、天气；可安装订阅、热榜、书签、监控、书桌、日历、番茄钟和音乐等 | 联网能力依赖用户配置与外部服务；安装状态影响可用组件目录 |
| 主题与恢复 | 主题库、明暗配色、字体、Dock 外观、默认外观还原、模板保存与应用 | 模板是设计快照，不包含全部业务数据；外观还原不会删除独立应用与特效块内容 |
| 声明式组件 | 列表、卡片、数字、文字、链接与 SVG 插图 | 适合数据展示，不是任意 React 页面生成 |
| AI 应用 | Applet 与 HTML 沙盒 App；安装、分组、设置、卸载、入口与页面挂载 | Applet 只能调用已注册的界面积木；安装 npm 包不等于应用内 AI 已可使用 |
| 数据展示 | `Bars`/`Table`、带明细的 `LineChart`、受控搜索/排序/分页与稳定 ID 选择的 `DataTable` | 有界客户端数据协议，不包含服务器分页、虚拟化或任意单元格编辑 |
| 特效 | 本地目录、参数校验、懒加载、组合预算、双主题配色、减少动画与失败降级 | 静态降级和运行标记不能证明完整像素呈现或视觉质量 |
| 本地数据 | 聊天/内置组件使用 IndexedDB；AI 应用仍用 localStorage；已有备份与 Gist/WebDAV/HTTP 同步 | 同步仍为整包传输；可靠性、应用迁移与可选增量服务正在规划，见存储里程碑 |
| 生成检查 | 读取源码/配置、`inspect_page` 有限 DOM 测量、草稿检查与修复后复查 | 没有截图或审美判断，iframe/Canvas 内部和完整对比度等保持未知 |

## AI 能力分层

- **内置与声明式组件**：已知功能和展示结构，优先复用。
- **特效素材**：用于背景、标题或局部装饰，不能代替信息结构。
- **Applet**：常规交互工具的首选，逻辑由 AI 编写，界面由宿主统一渲染。
- **沙盒 App**：用于游戏、Canvas/WebGL 或确需自定义视觉的场景，主题与交互要自行遵守宿主契约。

这些是运行方式与自由度的分层，不是质量排名。能力边界与设置行为见[运行时契约](../specs/runtime-contract.md)。

## 已接受的增强方向

2026-10-27 已接受的方向是先提高现有生成的可靠性，再增加表达能力：统一工具示例与设计规则，建立特效能力说明和检查反馈；随后补布局组合，最后扩展图表、数据列表和精选视觉组件。

极简启动页、效率工作台、编辑式内容页与视觉展示页四类组合，以及静态草稿、应用和撤销已交付。AI 搭建父任务的 9 个子任务均已交付，父任务跨功能组合验收仍待完成。目标契约见 [AI 页面生成质量](../specs/ai-page-design-quality.md)，进度见[本轮里程碑](../work/milestones/2026-10-27-ai-builder.md)。

2026-10-28 用户确认继续存储与同步方向：保留完整纯本地模式，允许可选自建同步服务。当前仍为研究和分期计划，不能宣称应用已迁入 IndexedDB 或服务已可用，见[存储与可持续同步](../work/milestones/2026-10-28-storage-sync.md)。

## 非目标与边界

- 不把堆叠特效数量当作设计质量，也不承诺某种模板能满足所有审美。
- 不向生成应用默认开放任意宿主组件、样式体系或完整 npm 运行环境。
- 不把源码检查、配置成功写入或打开应用，表述为已完成视觉验收。
- 本轮不改变本地优先的数据路线，不扩展为外部应用交易市场或多人实时协作产品。
