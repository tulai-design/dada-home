# 本地声明式主题包

决策状态：accepted，2026-10-30。实现状态：已实现；真实 Web/PWA 与 MV3 的验收记录由 Trellis 本轮任务维护。

## 包与主题的关系

主题包是一个本地 JSON 文件，携带不可变版本的设计定义与可选 WOFF2 字体。包 ID、版本和内容摘要共同确定精确依赖；摘要用于检查内容完整性，不证明作者身份或授予权限。主题实例仍保存完整设计快照，包来源不构成动态继承树。

包只能使用宿主已经提供的造型、外壳和字段目录，不包含可在宿主执行的 JavaScript、任意 CSS、HTML 或网络地址。新的可信外壳仍随应用构建；第三方可执行扩展需要另行设计隔离运行和能力授权，不由本地主题包安装路径承载。

## 文件合同与额度

文件外层为 `{manifest, resources}`。manifest 包含 `packageId/version/digest`、`kind: "declarative-theme"`、`schemaVersion: 1`、名称说明、`requiredRenderers`、主题 `contributions` 和资源清单。文件 resources 按 ID 保存 base64，实例中只保存紧凑引用，不把字体字节放入工作空间或草稿。

贡献设计里的字体只用 `resourceId` 指向同包资源；实例化才补上包 ID、版本、摘要和字体 sha256，避免包摘要引用自身。摘要对去掉 manifest.digest 后的规范 JSON 计算 SHA-256，对象键递归排序、数组保序；资源清单包含解码字节数和各自 SHA-256。相同 ID/版本/摘要重复安装幂等，同 ID/版本但不同摘要拒绝，不覆盖旧记录；新版本并存，没有自动升级或范围求解。

| 边界 | 上限 |
| --- | --- |
| JSON 文件 UTF-8 | 6 MiB |
| manifest | 64 KiB |
| 单份设计 / JSON 深度 | 32 KiB / 12 层 |
| 单字体 WOFF2 文件（base64 解码后） | 2 MiB |
| 单包字体总字节 / 字体数量 | 4 MiB / 4 个 |
| 单包主题贡献 | 8 个 |
| 本机全部版本资源 / 安装版本 | 16 MiB / 16 个 |

这些是应用处理额度，不是浏览器配额。安装校验 WOFF2 文件头、声明长度与摘要，启用时再通过浏览器实际解码；安装成功不等于字体已可用。安装还检查文件头声明的 SFNT 解压大小不超过每字体16MiB；中文大字体建议先生成子集。ID 不接受路径或 URL，结构拒绝未知字段与原型相关键。实现定义见 [`contracts.ts`](../../src/lib/themePackages/contracts.ts)；创建文件时优先从界面导出已有方案，再遵循同一 codec 更新摘要，不能任意手填摘要。

工作空间版本 9 增加精确 `packageRef` 与 `rendererContract`。已知设计走当前字段目录；未知 renderer 的合法设计和 `opaqueDesign` 只作为有界数据保留，不进入实际样式解释或作者编辑。未知包类型仅可保存可完整往返的有界 metadata envelope；无法保留或校验的资源明确拒绝，不以安装成功掩盖丢失。

## 安装、使用与回退

安装先校验文件、定义、摘要、资源和容量，成功后仅保存包，不自动切换当前主题。启用会准备资源；选择具体主题才更新工作空间。新版本与旧版本分别保存，失败不得覆盖旧版本或提前改变正式外观。IndexedDB 与工作空间配置不是跨引擎原子事务，操作按准备、持久化和提交的顺序处理失败。

停用保留资源、完整设计与精确请求引用，实际界面暂用可信基础外观；重新启用所需的精确版本后可恢复。缺包、停用、资源失败和合同不兼容分别报告。请求主题与实际渲染分开，不把回退主题写回用户设计；损坏输入仍拒绝。

卸载前检查主题、变体、模板和当前作者草稿的引用。有依赖时阻止物理删除并列出来源，用户可以先停用。包操作不复制设备授权、不修改应用数据命名空间，也不重建业务宿主。停止、审批、设置和保存故障恢复入口保持可达。

## 资源与预览

字体只能来自包内受控 WOFF2 字节；包设计显式使用本地资源或系统字体，不能借默认字体或字体变量隐式发起网络请求。内部 CSS family 由资源内容摘要确定，避免同名字体在准备阶段抢占正式样式。

正式界面与独立预览分别持有 document 字体 lease，通过 `FontFace(ArrayBuffer)` 加入对应的 FontFaceSet。释放时只移除自己创建的字体，不清空整个文档字体集合；超时、取消及旧请求迟到均不能重新注册资源。不创建字体对象 URL。

预览的主题控制消息继续限制为 64 KiB，字体二进制另有独立预算和校验，不能以资源消息携带任意代码或业务数据。独立预览仍是可信打包代码中的固定示例，不初始化工作空间、应用、聊天或同步。

## 保存、备份与同步

| 路径 | 设计与精确引用 | 包定义及字体字节 | 本机启用状态与设备权限 |
| --- | --- | --- | --- |
| 主题/模板快照 | 保留 | 不内嵌 | 不复制 |
| 完整本地备份 | 保留 | 包含全部安装版本 | 包恢复为停用；其他本机配置沿完整备份恢复规则，包本身不授予权限 |
| 配置快照同步 | 保留 | 不包含 | 不复制 |
| 完整业务快照同步 | 保留 | 不包含 | 不复制 |
| 加密增量同步 | 保留 | 不包含 | 不复制 |
| 原包导出 | 原包全部定义，身份/摘要不变 | 原包全部本地资源 | 不包含 |
| 当前方案导出 | 单个完整设计，新包身份与版本 1.0.0 | 所需精确资源闭包 | 不包含 |

“完整业务同步”不等于主题资源分发。另一台设备收到设计但缺包时保留引用并说明缺少的精确版本；用户通过包文件安装，或使用完整备份恢复资源。读取资源库失败时不能导出空数组并宣称完整备份成功。

未知包类型和未知渲染合同只保留经过预算与结构校验的数据，标为不可用，不尝试执行，也不因为当前宿主未注册而静默丢弃。导出当前主题若仍依赖远端字体或缺少本地资源，应解释原因并拒绝不完整导出，不悄悄删掉字体。
