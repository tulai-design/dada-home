# 搭搭书签桥：应用商店上架材料

提交 Chrome 网上应用店（一次性 5 美元开发者注册费）和 Edge 加载项商店（免费）时，可以直接复制下面的内容。两个商店的字段基本一致。

安装包：`pnpm pack:ext` 生成 `public/dada-bookmarks-extension.zip`，直接上传这个 zip。上架通过后，把商店地址填进 `src/lib/browserBookmarks.ts` 的 `EXTENSION_STORE_URL`，页面里的安装步骤就会变成一个「去安装」按钮。

## 基本信息

| 字段 | 内容 |
| --- | --- |
| 名称 | 搭搭书签桥 |
| 分类 | 工作效率（Productivity） |
| 语言 | 简体中文（可另加英文） |
| 版本 | 与 `extension/manifest.json` 的 `version` 一致，每次提交都要比上一版大 |

### 简短说明（132 字符以内）

让搭搭读取、整理你浏览器里的书签。只在你手动启用的网站上工作，不读浏览历史。

### 详细说明

搭搭书签桥是 搭搭（tulai.design）个人起始页的配套扩展。网页本身没有读取浏览器书签的权限，装上它之后，搭搭就能：

- 把浏览器里的书签导入搭搭的书签页，按文件夹分组
- 把搭搭里整理好的书签同步回浏览器（只在书签栏新建一个「搭搭」文件夹往里添加，不改动、不删除你原有的书签）
- 让搭搭的 AI 帮你整理和归类书签

怎么用：
1. 安装扩展
2. 打开搭搭，点工具栏里的扩展图标
3. 点「在此网站启用」，浏览器会询问是否允许扩展访问这个网站，同意后即可

隐私与安全：
- 默认对任何网站都没有访问权限；只有你在某个网站上点了「在此网站启用」，才会申请那一个网站的权限，随时可以在弹窗里关闭
- 不读取浏览历史，不收集任何数据，不联网，不含任何统计或广告代码
- 书签只在你的浏览器和你启用的那个网页之间传递，不经过任何服务器
- 不会删除书签文件夹

## 商店后台要填的声明

### 单一用途（Single purpose）

让用户启用的网页（搭搭）读取并整理浏览器书签。

### 权限用途说明（Permission justification）

| 权限 | 说明 |
| --- | --- |
| `bookmarks` | 核心功能：读取书签树，以及在书签栏下新建「搭搭」文件夹并添加书签。不删除文件夹。 |
| `activeTab` | 用户点开扩展弹窗时，读取当前标签页的地址，用来显示和启用当前网站。不读取页面内容，不读取浏览历史。 |
| `scripting` | 用户点「在此网站启用」后，向这一个网站注册并注入内容脚本，用来在网页和扩展之间传递书签请求。关闭后会注销。 |
| `storage` | 在本地保存用户已启用的网站列表，下次打开浏览器时还能恢复。不保存任何书签内容。 |
| 可选主机权限 `http://*/*`、`https://*/*` | 不在安装时申请。仅当用户在某个网站上点「在此网站启用」时，通过 `chrome.permissions.request` 申请那一个网站的权限。 |

### 远程代码（Remote code）

不使用。扩展的全部代码都在安装包内，不加载、不执行任何远程脚本。

### 数据使用披露（Data usage）

- 不收集个人身份信息、健康信息、财务信息、认证信息、位置、网页内容、用户活动
- 「个人通信」「网站内容」也都不收集
- 勾选三项承诺：不向第三方出售用户数据；不为与单一用途无关的目的使用或传输数据；不为判断信用或放贷目的使用或传输数据

说明：书签数据会从浏览器传给用户自己启用的那个网页，这是用户主动发起、功能本身需要的传递，不属于扩展向开发者或第三方收集数据。

## 隐私政策

商店要求有一个可公开访问的隐私政策链接。搭搭站点已经带了一个页面 `public/privacy.html`（线上地址是 `https://你的域名/privacy.html`，也可以用 `/privacy`，会自动跳转），把这个链接填进去即可。页面内容覆盖网页应用和扩展，下面这段是扩展部分的摘要，改动时两处保持一致。

> **搭搭书签桥隐私政策**
>
> 搭搭书签桥不收集、不存储、不传输任何个人信息到开发者或第三方。
>
> 扩展会在用户主动操作时读取浏览器书签，并只把它们传给用户自己启用的那个网页（搭搭）。扩展本身不联网，不含统计和广告代码，不读取浏览历史和网页内容。
>
> 扩展在本地保存用户已启用的网站列表（`chrome.storage.local`），卸载扩展时一并清除。
>
> 对任何网站的访问权限都由用户逐个授予，并可以随时在扩展弹窗中撤销。
>
> 如对本政策有疑问，请通过搭搭的项目主页联系我们。

## 提交流程

1. Chrome：登录 [Chrome 开发者控制台](https://chrome.google.com/webstore/devconsole)，缴 5 美元注册费，新建项目、上传 zip，填写上面的内容，提交审核（通常几天，申请「可选主机权限」和 `scripting` 可能会多问几句，把上面的权限说明贴上去即可）
2. Edge：登录 [Partner Center](https://partner.microsoft.com/dashboard/microsoftedge/overview)，免费注册后上传同一个 zip，内容基本照搬
3. 通过后把两个商店的地址告诉我（或自己填进 `EXTENSION_STORE_URL`），安装按钮就会变成一键跳转。现在这个常量只有一个，两个商店都有时可以按浏览器判断，需要的话我再改。
