# 使用指南

[返回项目首页](../../README.md) · [部署指南](deployment.md) · [开发指南](development.md)

本页保留 AI 配置、应用运行、数据与同步、扩展安装的详细说明。初次使用可以先在主页添加组件，再到设置连接 AI；不配置 AI 也能手动搭建和使用本地工具。

## AI 助手

在「设置 → 搭搭 AI」填写服务商、接口地址、模型和 API Key。支持 OpenAI Chat Completions 与 Anthropic Messages 两种协议，以及 Markdown 回复、多轮对话和工具调用；页面搭建与站内操作需要模型支持工具调用。

接口协议默认自动选择：AiHubMix 的 Claude 模型、Anthropic 官方服务和以 `/messages` 结尾的地址使用 Messages，其他服务使用 Chat Completions，也可以手动指定。AiHubMix 可填写 `https://aihubmix.com/v1`，选择 `claude-haiku-5-5`；GPT 等模型继续使用 Chat Completions。Messages 直接处理原生工具调用，并在后续工具轮次保留思考签名，避免网关转成 OpenAI 格式时丢失信息。

Claude 的推理强度按模型版本映射：支持自适应思考的新版本使用 `thinking.type: "adaptive"` 和 `output_config.effort`，旧版思考模型使用 token 预算。「默认」不覆盖模型的思考设置。Messages 要求输出上限，未填写时使用 16,384 token；可以在高级设置中调整。

点击左上角搭搭 Logo 可恢复侧边聊天，默认使用抽屉，并记住上次选择的抽屉或分栏。桌面聊天标题栏可切换抽屉、分栏和全屏；分栏把页面放左侧、聊天放右侧，中间分隔线可拖动或用方向键调整，比例保存在本机。切换页面、进入设置、打开应用和阅读文章不会关闭分栏聊天，应用弹层仅覆盖左侧画布。窄屏自动以抽屉显示，恢复宽屏后保留分栏偏好。Dock 和 `⌘J / Ctrl J` 使用「设置 → 搭搭 AI → Dock AI 入口」中的独立偏好。

AI 可以发现已注册的组件和可用操作，创建页面、编辑布局与配置、切换主题、保存模板，也可以管理订阅、待办、便签、日程和书签。工作空间修改经过参数校验并进入撤销历史；删除等高风险工具调用会按权限设置请求确认。助手内置的技能说明提供设计规范、组件与小程序的使用约定。

首页改版可以先试布局草稿：让搭搭生成方案，或在命令面板选择「预览首页方案」，在极简启动、效率工作台、编辑式内容和视觉展示之间切换。检查和调整后可整体应用、取消或撤销；现有组件、应用 ID 和数据保留。预览只展示静态布局，实时数据、应用内部和动态背景不运行；未应用的草稿刷新后丢弃。

主题支持分别保存浅色和深色配色，切换明暗会使用对应的一套，圆角、字体和外框等设计可以共用。AI 创建完整主题时需要提供两套配色；旧主题只有一套时，保留原有模式的设计，另一模式使用系统基础配色。主题的初始明暗偏好不会阻止用户切换，刷新后保留最后选择；模板和备份也会保留两套配色。

首次使用默认采用 iOS 主题与玻璃 Dock，纸张等其他主题仍可选；已有保存的外观选择继续保留。

可以让搭搭「恢复默认外观」：它会恢复 iOS 主题、对应字体与无外框外观、玻璃 Dock 和首页默认背景，并清理各页额外的壁纸、背景特效图层、页面样式与组件外观。页面内容、组件顺序和布局、业务数据、已存主题和模板都会保留，当前明暗也保留，支持撤销。独立特效组件和自编应用也作为内容保留，助手会列出它们，方便继续检查。只想还原首页背景时可以直接说明；只切回纸张配色则会保留已有背景与装饰。助手可先读取默认外观与当前差异，再执行还原并核对结果。

自定义内容有三种主要方式：

| 方式 | 适用内容 | 实现方式 |
| --- | --- | --- |
| 声明式组件 | 列表、卡片、统计、链接、文字与 SVG 插图 | AI 描述数据源和显示规格，由现有渲染器呈现 |
| 小程序（Applet） | 计算器、换算、生成器等交互工具 | AI 编写 JavaScript 逻辑，在隔离沙盒中运行，界面由主页使用 Lobe 控件渲染 |
| 沙盒应用（App） | 游戏、Canvas / WebGL 或完全自定义的视觉内容 | AI 编写 HTML / CSS / JavaScript，在隔离 iframe 中运行 |

AI 创建的 App / Applet 默认安装到「组件市场 → 我的应用」，可以搜索、按分组查看、打开、进入设置或卸载。应用独立保存在工作空间的应用目录中，不要求拥有页面，也不会自动加入 Dock；旧页面中的应用会按原 ID 纳入目录，保留内容和私有数据。

应用支持窗口、抽屉和全页面打开，默认方式在应用设置中选择。桌面窗口用左上角交通灯关闭、最小化和最大化／还原，可拖动标题栏；最小化会保留运行状态，点击画布底部的应用名可恢复。窗口内只保留标题和窗口操作，应用设置从组件市场或设置页进入。Dock 和顶部状态栏按需启用；页面小组件可选择挂载页面与宽度，取消挂载仍保留应用。状态栏既可显示启动按钮，也可运行应用提供的单行紧凑视图；源码需要明确适配 `surface: "status"`。同一应用的独立窗口、可见小组件和紧凑视图由宿主协调，避免同时运行多份逻辑改写同一份数据。

「设置 → 应用」会显示每个已安装 AI 应用的设置入口。AI 用 `settingsSchema` 声明字符串、数值、开关或选项字段后，系统生成设置表单；App 通过 `tada.settings` / `tada.surface`，Applet 通过 `ctx.settings` / `ctx.surface` 读取设置与当前形态。用户设置与应用业务数据分开保存。卸载移除应用、入口和页面小组件，保留本机私有数据，支持撤销找回。

普通交互工具优先使用 Applet。`ctx.viewport` 提供实际容器宽度和小于 480px 的 `compact` 标记，网格默认按容器收列；设置变更可用 `onSettingsChange` 更新定时器、数据源等副作用。App 的主题变量会热更新，设置变更会安全重载并保留 `tada.store`。应用只在挂载的运行形态中执行逻辑，所有形态卸载后不提供后台常驻任务；切换形态所需的业务状态应持久化。写法、完整创建参数和各形态尺寸见内置 `applet` 技能及[设计规范](../design-system.md)。

Applet 数据展示支持简单柱状图 `Bars` 和趋势折线图 `LineChart`。趋势图沿用深浅主题，按实际容器减少刻度，缺失记录画断线，准确数值可展开查看；最多120个点、4条系列，超量会提示先整理数据。可以让搭搭制作带本地记录、设置和趋势明细的小工具。

记录型工具可使用 `DataTable` 搜索、排序、分页和选择记录。手机与窄抽屉优先显示关键字段，通过详情读取完整内容；选择按稳定ID跨页保留。简单静态展示继续用 `Table`。表格最多500行、8列；App / Applet 业务状态统一存入 IndexedDB，每个实例的 JSON 总数据最多 8 MiB（按 UTF-8 字节计）。表格行列限制与保存容量分别生效。

助手生成后可以读取并核对应用源码、设置与入口，通过 `inspect_page` 获取当前挂载页面的有限DOM测量；目前没有浏览器截图反馈，无法仅凭测量确认视觉效果、对比度或完整无障碍。

自定义组件、App 和 Applet 访问新域名时会请求用户确认，拒绝后不发取数请求。允许后，等待中的 `tada.fetch` / `ctx.fetch` 可以继续；授权可在「设置 → 网络」撤销。App 的图片和媒体域名受文档 CSP 控制，新授权需要切换页面再返回，或修改应用源码后生效；撤销已有域名会立即重新生成文档并收紧权限。

阅读器中的「带着这篇文章去问」会先附上文章并打开提问草稿，等用户发送后才请求模型。会话保存文章标题、链接与订阅提供的正文或摘要，后续追问仍可使用；只有标题和链接的订阅不会被当作全文生成摘要。

聊天记录按需读取：打开会话先加载最近40轮，向前翻页再读取更早内容；会话列表每页50项。历史工具只展示动作与结果状态，展开后读取完整正文。生成中可以查看其他会话，输出仍保存到原会话，返回后继续查看；同时只运行一次提问。

界面分页与模型上下文独立。模型默认读取最近24轮、约36,000个JavaScript字符的问答及参考文章（轮数可设置）；思考与历史工具正文保存在本机，但不进入下一轮历史上下文。分页不会裁剪或删除历史，完整备份和完整同步仍包含所有轮次与工具原文。

联网搜索在「设置 → 联网搜索」单独配置，支持 Tavily、Firecrawl、SearXNG、Exa 和 Brave。助手还可以打开浏览器搜索结果页；打开搜索页与由助手读取搜索结果是两种不同的操作。

## 本地数据与备份

数据默认保存在当前浏览器、当前站点下：

| 存储 | 内容 |
| --- | --- |
| localStorage（`fp.` 前缀） | 工作空间结构、应用目录、主题与模板、设置、用户画像与记忆、已读记录等 |
| IndexedDB | 组件业务数据、App / Applet 独立应用数据、会话与对话轮次 |

在「设置 → 数据」中可以导出或导入备份，备份涵盖两类存储。**导入备份会整体替换当前数据，并重新加载页面，不会与现有数据合并。** 模板则保存页面设计快照，可包含主题，不包含待办、便签等组件业务数据。

保存失败时会显示提示并保留待写更改，点击「重试保存」成功后再关闭页面。导出会先等待已接受的更改保存成功；读取或保存失败不会导出空表冒充完整备份。当前完整备份为 version 3，必须包含应用数据与聊天工具正文表，不接受旧格式；整包读取预算为 256 MiB，与浏览器存储容量无关。

恢复前请停止 AI 回答并关闭其他搭搭标签页。恢复会先校验文件，再用本机恢复日志保护原数据；中断后下次启动会尝试回到替换前的状态。恢复需要支持 Web Locks 的浏览器。损坏的旧配置及残留旧业务键会原样保留供救援，含旧业务入口的文件不能通过新版格式自动导入；启动失败页提供的「原始配置」仅用于救援，不是包含数据库的完整备份。

使用 AI、联网搜索、订阅、天气或监控等功能时，会向对应服务发送请求；开启同步后，所选数据会上传到你配置的存储。AI 服务的 API Key 等连接信息也保存在浏览器中，只应在可信设备上填写。隐私说明见 [隐私政策](../../public/privacy.html)。

### 跨设备同步

在「设置 → 同步」中选择 WebDAV、GitHub Gist、自建 HTTP 或自建同步服务。前面三种使用快照协议，下节介绍的自建服务采用加密增量协议；可以手动同步或开启自动上传。

| 后端 | 同步范围 | 并发写入 |
| --- | --- | --- |
| GitHub Gist | 页面、主题、应用源码和设置、可携宿主偏好、当前 AI 性格配置；不含聊天、画像、累积记忆或业务状态 | 不支持条件更新保护，避免多设备同时同步 |
| WebDAV / 自建 HTTP | 可携配置、组件与应用业务数据、画像和记忆、已结束的聊天 | 远端提供强 ETag 时使用条件更新；否则明确提示无保护 |

同步使用 `dada-sync-v2.json` 新快照协议，不读取或转换旧同步格式。按配置、组件数据、应用状态、会话和对话轮次等逻辑记录合并；版本由逻辑计数、设备标识和内容摘要确定，删除通过墓碑传播，不是逐字段合并或实时协作。首次连接时，同名记录以远端为基线，本机独有记录仍会上传。

可以设置口令加密整个快照；未设置口令时，普通数据为明文。已知 API Key 等凭据默认排除，开启「同步密钥」必须设置加密口令。更换或移除加密时，可填写仅供本次读取的原云端口令；关闭密钥同步会清理最新快照中的已知凭据，不能擦除存储方历史版本。应用源码和自由文本里的手写密钥仍需自行检查。

网络授权、同步连接、设备连接和运行状态保留在本机，各设备分别配置。同步期间发生本机修改会保留修改并提示重试；收到远端更改后会暂时阻止旧内存继续编辑；用户未在输入时自动重新加载，正在输入时等离开输入框后再加载，避免覆盖输入和新数据。存储故障、坏快照和错误口令不会作为空数据上传。

自动同步在启动、恢复联网和定时检查时上传本机变更；完整拉取通过「立即同步」触发。首次上传前保存未完成同步的采样基线，失败后重试或刷新后重试仍会保留上传期间的新编辑。

Gist / WebDAV / 自建 HTTP 快照仍为整包传输：每次读取快照，有变更时重写文件。UTF-8 正文处理预算为 Gist 8 MiB、WebDAV / HTTP 64 MiB，加密和 Gist 请求包装也占预算；它们不是浏览器容量或供应商配额。界面展示的正文收发字节不包含 HTTP 头，也不代表压缩后的实际网络流量。S3 尚未接入。

WebDAV / HTTP 服务需要支持 GET、PUT、条件请求和相应跨域访问，或使用独立的读写代理。搭搭内置取数代理只支持 GET，不能用于同步；连接测试只读取目标，不写远端。Gist ID 留空时尚未创建目标，连接测试不能验证令牌权限，首次同步才会尝试创建。

### 自建同步服务

「设置 → 同步」里选择「自建同步服务」，只粘贴一把同步密钥。密钥在同步服务的管理页生成：用管理员令牌登录后，每个已授权的应用各有一把，同一服务的各端填写同一把。一台服务器可以同时给多个应用使用。数据在上传前加密，不需要再设置快照同步的口令。

自动同步只上传，手动同步会拉取；新数据保存后页面按输入状态安全重载，再继续编辑。两端改了同一条时，在同步页选择保留哪一版。详见[增量同步契约](../specs/application-incremental-sync.md)。

## 浏览器扩展

### 完整新标签页

在网页版「设置 → 浏览器扩展」下载完整 ZIP，解压到固定目录；打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，选择「加载已解压的扩展程序」，加载包含 `manifest.json` 的目录。打开新标签页后，确认保留搭搭作为新标签页。

完整扩展共用现有主页、主题、Dock、内置组件、AI 搭建、App/Applet、书签、备份与同步。首次连接外部服务时，点击「允许连接」申请对应来源权限；内置 `/__proxy` 预设在扩展中直接连接目标，自定义远程代理仍按配置使用。AI、RSS 等在线服务仍需网络和自己的连接配置。

扩展的 API/订阅请求遇到重定向会停止并提示使用最终地址，避免自动跳转到未授权的来源。系统通知权限用于保留专注完成提醒，能否显示系统横幅还取决于浏览器与系统通知设置。

```sh
# 单独构建完整扩展
pnpm build:extension
```

输出 `dist-extension/` 可直接加载，`public/dada-extension.zip` 可下载分发。常规 `build` 同时生成完整扩展包并放入网站 `dist/`，下载入口无需外部商店。扩展与 Web/PWA 分别构建，扩展不注册网页 Service Worker，也不加载远程统计脚本。

网页版与扩展数据独立，可在「设置 → 数据」导出/导入备份，或配置相同同步服务。多个搭搭标签页使用一个完整运行实例；额外页面可点击「回到搭搭」，运行页面关闭后等待页面自动接续。关闭运行页面会中断当前 AI 回答，未承诺后台持续运行。

更新前导出备份、关闭搭搭标签页，将新 ZIP 覆盖解压到原目录，再在扩展管理中点击重新加载。保留原目录和扩展身份，不要用卸载重装更新，以免清除扩展本地数据。当前为开发者模式自用版，未上架商店。

### 网页配套书签桥

配套的「搭搭书签桥」是 Chrome / Edge 的 Manifest V3 扩展，用于读取、整理浏览器书签，以及在浏览器书签栏的「搭搭」文件夹中添加书签。扩展仅在用户手动启用的网站上工作。

`pnpm pack:ext` 会生成 `public/dada-bookmarks-extension.zip`，`pnpm build` 也会自动打包。当前可在浏览器扩展管理页开启开发者模式，加载已解压的 `extension/` 目录，再在搭搭站点启用扩展。

详细步骤见 [扩展说明](../../extension/README.md)。[应用商店上架材料](../extension-store-listing.md) 已包含介绍、权限用途和隐私说明；商店截图与安装地址仍需补齐。
