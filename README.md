# 搭搭 · tulai.design

> 陪你把想法，搭成自己的主页。

**搭搭**是一个亲切、有帮助的 AI 个人主页搭建助手，也是图来设计（[tulai.design](https://tulai.design)）的一颗新星。

你可以告诉搭搭“给我做一个安静的阅读主页”“把天气和待办放在一起”，它就能借助一套清晰的组件、主题和布局约定，帮你组织出更适合自己的页面。你也可以自己动手细调。主页属于你，数据留在你的设备上。

搭搭的目标不是把 AI 塞进一个固定模板，而是让每个人都能用自然语言和简单编辑，持续搭建、调整自己的数字空间。

## 我们想做成什么

- **说出想法，AI 帮你搭建**：通过内置的 AI 工具、MCP/Skill 和项目文档，让 AI 能理解有哪些组件、主题与布局可用，并按稳定约定组合和调整它们。
- **每一块内容都可以组合**：页面由组件构成。资讯、工具、书签、天气、待办等组件可以添加、移动、调整，也可以逐步扩展出新的组件和页面。
- **组件有自己的设置**：每个组件可以声明自己的配置项和设置界面，保存专属数据，同时遵循统一的组件协议。
- **主题和布局都能定制**：内置好看、好用的主题与布局作为起点；用户可以修改布局，主题也可以从统一、丰富的 CSS 变量延展。
- **本地优先，用户做主**：页面、主题、组件配置和个人数据默认保存在浏览器本地，支持完整导入与导出。
- **让扩展有章可循**：组件协议、主题变量、AI 可调用的操作和开发文档一起演进，让 AI 与开发者都能可靠地扩展搭搭。

## 项目现状

当前仓库是搭搭的早期原型：已有个人主页界面、订阅与阅读、书签、待办、便签、天气、热榜、服务监控、AI 对话和本地备份等功能。应用使用 React、TypeScript 和 Vite，核心页面及数据流在 `src/App.tsx`，界面组件在 `src/components/`，数据与服务逻辑在 `src/lib/`。

上述 AI 页面搭建、可扩展组件协议、可编辑布局和完整主题系统是产品方向，仍在逐步建设中。当前版本的卡片和页面结构仍有一部分是固定实现；AI 对话目前通过用户填写的 OpenAI 兼容接口工作。

## 开始使用

需要 Node.js 与 pnpm。

```bash
pnpm install
pnpm dev       # http://localhost:5173
pnpm build     # 类型检查并构建到 dist/
pnpm preview   # 本地预览生产构建
```

项目的 Vite 开发服务器提供 `/__proxy?url=…` 转发，用于请求受浏览器跨域限制的 RSS、热榜和监控接口。它只用于开发；生产部署需要配置自己的取数代理。

## 本地数据与备份

当前版本把用户数据保存在浏览器 `localStorage`，使用 `fp.` 键前缀，包含书签、订阅、待办、便签、已读记录、设置和监控配置。设置中可以导出和导入备份。项目没有应用后端，也不会把这些数据上传到项目服务器。

AI 服务的 API Key 也保存在浏览器中。请只在可信设备上填写；页面中运行的脚本可以访问浏览器存储。

## 生产取数代理

浏览器直接请求 RSS 或部分监控服务时，可能受到跨域策略限制。项目提供了一个可部署的 Cloudflare Worker：

```bash
npx wrangler deploy worker/proxy.ts --name tada-proxy
```

部署后，在「设置 → 订阅与取数 → 取数代理」中填入代理地址模板：

```text
https://tada-proxy.<你的账号>.workers.dev/?url={url}
```

建议在 `worker/proxy.ts` 的 `ALLOW_HOSTS` 中列出需要访问的域名，限制代理目标范围。

## AI 助手

当前原型支持在「设置 → AI · BYOK」填写 OpenAI 兼容服务的接口地址、模型和 API Key。消息通过流式 `chat/completions` 请求发送，支持 Markdown 回复。首页摘要、助手对话和阅读器摘要共用这份配置。

后续的 AI 原生工作流会围绕组件协议和工作空间数据构建：AI 能发现可用能力，创建页面与组件实例，修改布局和配置，并在应用变更前让用户检查结果。MCP/Skill 将提供可发现的操作与可靠的上下文，文档则作为 AI 和开发者理解扩展约定的依据。

## 设计与扩展原则

搭搭将以下约定作为后续实现的基础：

1. **统一主题令牌**：颜色、字体、字号、间距、圆角、阴影和表面层级通过 CSS 自定义属性提供；内置主题和扩展组件遵循同一套令牌。
2. **稳定组件协议**：组件有明确的标识、名称、描述、默认配置、数据约定、渲染入口和可选设置界面，供页面系统与 AI 发现和使用。
3. **组件实例数据化**：页面中的组件实例、顺序、布局和配置以结构化数据保存，支持校验、迁移、导入与导出。
4. **渐进式扩展**：优先使用内置组件与基础 UI 组件库（包括 LobeHub UI）；在协议、隔离和权限约定成熟后，再逐步支持 AI 辅助创建自定义组件。
5. **本地优先**：核心页面体验不依赖应用后端；AI 接入由用户选择和配置，用户可随时备份自己的工作空间。

## 品牌

**搭搭**是图来设计（tulai.design）的 AI 个人主页搭建助手。名字亲切、好记，也表达了“陪你一起搭起来”的感觉。它和图来设计旗下的 **齐默默** 一样，希望把复杂能力变成日常、顺手、真正帮得上忙的工具。
